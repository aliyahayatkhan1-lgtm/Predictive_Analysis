# 📈 Predictive Analytics Using Historical Data

## 📌 Project Overview

Predictive Analytics Using Historical Data is a machine learning project that analyzes historical monthly sales data and predicts future sales trends.

The project uses Linear Regression to learn patterns from historical data and generate future sales predictions.

## 🎯 Objectives

- Analyze historical sales data
- Clean and preprocess the dataset
- Build a predictive machine learning model
- Evaluate model performance
- Compare actual and predicted sales
- Forecast future sales
- Visualize historical and predicted trends

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## 📊 Dataset

The dataset contains monthly sales records from 2024 to 2026.

### Dataset Columns

| Column | Description |
|---|---|
| Month | Month of the sales record |
| Sales | Total sales for that month |

The dataset contains 36 months of historical sales data.

## 🤖 Machine Learning Model

### Linear Regression

Linear Regression is used to identify the relationship between time and sales.

The model learns the historical sales trend and uses it to estimate future sales.
